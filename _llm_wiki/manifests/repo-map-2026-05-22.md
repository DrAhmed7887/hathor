## Code areas

### `api/` — Python backend
- Stack: FastAPI + Claude Agent SDK, Python managed by `uv`
  (`pyproject.toml`, `uv.lock`).
- Package: `api/src/hathor/`
  - `agent_prompt.py` — system prompt for the reasoning agent.
  - `run_agent.py`, `hello_agent.py` — agent entry points.
  - `server.py`, `server_sessions.py` — FastAPI app. Exposes
    `POST /validate-schedule` over the rules engine.
  - `parsing/` — input parsing for cards / payloads.
  - `safety/` — Phase D and Phase E gate logic.
  - `schedules/` — country-schedule lookups.
  - `schemas/` — Pydantic models.
  - `specialists/` — parallel specialist agents (see auto-memory:
    five-specialist fan-out architecture).
  - `tools/` — custom tools the agent can call. `dose_validation.py`
    is the rules-engine entry point.
  - `fhir/` — FHIR resource builders (Provenance, etc.).
  - `flagship_scenario.py` — the flagship Nigeria→Egypt scenario.
- `api/tests/` — backend tests.
